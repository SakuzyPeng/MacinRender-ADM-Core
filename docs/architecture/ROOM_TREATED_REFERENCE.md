# 分区参考听音室试听候选

房间为 7 × 6 × 3.2 m，监听点为 (3.4, 3.0, 1.2) m。制作定义给出原生 48 和 96 kHz 两套候选。侧墙和顶面处理早反射，听位下方的吸声区覆盖上方参考声源的地面反射，后墙一维扩散体的主扩散轴水平。后墙近角设置低频陷阱。中央地面嵌入区按开放格栅下的等效吸声组件建模。低频结果描述频带衰减，单个驻波的峰值与衰减需要独立的模态测量。

## 制作与加载

以任一正式采样率模板制作对应房间。试听候选使用独立 ID。

~~~sh
python3 -B scripts/room/generate-room.py \
  --template-package resources/rooms/reference-7x6x3.2-corrected-v1/room.json \
  --definition scripts/room/treated-reference-v2.json --jobs 4 --output /path/candidate-48
build/release/mradm room-check /path/candidate-48/room.json --hrir /path/personal-collection
python3 -B scripts/room/check-acoustics.py --probe build/release/mr_adm_room_omni \
  --room /path/candidate-48/room.json --output /path/report-48.json
python3 -B scripts/room/check-surface-treatments.py --probe build/release/mr_adm_room_omni \
  --room /path/candidate-48/room.json --jobs 4 --rays 100000 --output /path/treatments.json
~~~

96 kHz 使用同一制作定义和 fullband-96k 模板。两个采样率的物理晚场预延时都是 18 ms，使用各自完整的频带滤波器和保护延迟。96 kHz 的可听频段与 48 kHz 共用随机激励，另一个独立种子流生成上半频段，再用原生 96 kHz 滤波器及能量包络合成。两包沿用同序的 32 个世界方向。SHA256SUMS 覆盖清单、定义和数值资产，运行环境和用时保存在独立的制作报告。

## 材料和边界规则

制作定义版本 2 生成清单类型 `hybrid-shoebox-v2`。将 `surface_model` 作为早晚场共用的材料来源。材料有唯一 ID、八带吸收率和散射率，数值范围为 [0, 1]。各带以模板滤波器为准，最低带同时覆盖 63 和 125 Hz。材料文件标注安装方式、测量依据和估计范围。扩散板的角向模型参考一维扩散体的方向特性；低频组件的有效吸收曲线参考刚性背衬安装测量，格栅、分频散射和缺测高频均属模型估计。[RPG 一维扩散体](https://www.rpgacoustic.com/wp-content/uploads/2022/07/QRD-734-Data-Sheet.pdf) · [Deep 6 安装测试](https://auralex.com/content/performance/deep6amount.pdf)

六个面依次为 X−、X+、Y−、Y+、Z−、Z+。局部 U/V 分别取房间的 Y/Z、X/Z、X/Y，坐标随房间正轴递增，单位米。每面有默认材料和有序的简单多边形覆盖区。顶点和落点就近量化到微米，半格向上。边界属于多边形，共边或重叠时采用后声明的区域。支持凹多边形。自交、越界、重复顶点、零面积及折返边在加载时拒绝。

射线每次反射保留 `1−α` 的能量，以概率 `s` 散射。默认散射遵循 Lambert 分布。`fan` 材料的 `angle_deg` 从 U 向 V 定义板的**扩散轴**。散射分支保留入射方向沿槽向的切向分量，在扩散轴与内法线构成的平面内按余弦分布抽样，输出方向为单位向量。散射分组考虑全部可能命中的材料。镜像早反射保留每次命中的镜面振幅 `sqrt((1−α)(1−s))`。

CPU 将听者到镜像源的线段与展开房间的网格面求交，折回实际墙面后查材质，支持配置的所有反射阶数。角点按固定轴序处理。准备阶段计算八个材料频带的频谱，工作区预分配 32 个材料组合频谱槽。换房、头部转动和多点扩展声源继续走共用的 ROOM 会话。离线渲染、文件流式渲染和 Scene 流式渲染均可使用。v1 走既有的逐镜像预计算路径。显式 CUDA 试验模式对分区房间报告不支持。

## 校准与验收

用原有 28 个声源位置先测平直 EQ、晚场能量 0.215 的原始响应。按实测反射落点调整中央楼板、顶面和侧墙深吸声区，再调整墙脚和顶部处理区的覆盖范围。最后对整个房间应用一条共用最小相位 EQ 和一个晚场增益，两种采样率共用物理频率控制点。EQ 在频率控制点间线性插值 dB，以实倒谱生成因果 FIR，再对有限末端淡出。校准针对固定几何和这组位置。完整响应使用既有的反射、T20、邻带变化、频响及 2 dB 通道差门槛。

报告还列出完整响应 EDT、理想全向晚场的八带 EDT/T20/T30。将各方向 FIR 对全向接收器求和、经过共用 EQ，与按直达、预延时和保护帧对齐的原生晚场用同一组八带滤波器分析。射线直方图的衰减另列。处理组件对照保留两个独立射线种子，分别检查侧墙处理区移动、扩散板旋转、移除壁挂低频陷阱的影响。

候选的声学报告、同响度试听和性能结果随候选包交付。正式预设收录在试听后决定。

### 2026-11-27 候选结果

| 采样率 | 原始 T20 检查通过位置 | 校准后全部通过位置 | 校准后最大通道差 | 最强早反射 |
|---|---:|---:|---:|---:|
| 48 kHz | 0/28 | 28/28 | 1.870 dB | −16.75 dB |
| 96 kHz | 0/28 | 28/28 | 1.855 dB | −16.75 dB |

共用 EQ 控制点为 −7.93 至 +7.51 dB，晚场能量为 0.464496。两个采样率的中频 T20 均值约 0.265 s。校准和验证均采用上述 28 个位置。两次独立追踪中，移除壁挂陷阱使最低带 T20 延长约 0.192 s；旋转后墙扩散板使 50–350 ms 到达方向能量张量的 Y−Z 分量分别改变 −0.0233 和 −0.0229。

macOS arm64 和 Windows x64 的 exact 合成回放共 17 个数值输出逐位相同。最终 Windows Release 的 96 kHz、512 帧、8 workers、32 源短测中，位置运动和距离运动平均分别为 13.84 和 14.37 ms，两项各有 1024/1024 次超过 5.33 ms 截止。本次交付为离线试听候选。

## 固定虚拟音箱校准

[48 kHz 房间](../../resources/rooms/candidates/treated-reference-v2-48000/room.json) 和 [96 kHz 房间](../../resources/rooms/candidates/treated-reference-v2-96000/room.json) 携带各自的原生校准数据。选用这两个包并使用自动坐标映射时，离线渲染、文件流式渲染和 Scene 流式渲染共用同一音箱输入级。7.1.4、9.1.6、22.2 的完整全频与 LFE 标签集确定布局，允许任意输入次序以及并存的 Objects。对于已识别的 Core Audio 标称布局，声道馈送到该布局的实测虚拟扬声器。自定义摆位、显式均匀米制比例以及直接按坐标渲染的 Objects 使用各自的传播模型。移动 Scene 扬声器离开校准位置时按其位置传播，返回时恢复校准。

每个全频声道先在输入端施加整数采样延时和标量增益，再进行房间传播和双耳渲染。LFE 使用同一监听点测得的因果 FIR，20–120 Hz 相对中置目标为 +10 dB。22.2 分别验过两个 LFE 输入；ROOM 采用共用的正前方低音响应。校准以头部中心的全向接收器为参考，500 Hz–2 kHz 粉红噪声复测全频电平。48/96 kHz 的全频箱间电平差均小于 0.02 dB，直达声到达时间差小于一个对应采样。听者个人 HRIR 和下游耳机补偿另行选用。

带校准的清单使用 `mradm.room` 版本 2，`speaker_calibration.version` 为 1。`layouts` 以布局名为键，各项按 `mradm input-layouts` 的 WAVE 顺序声明 `delay_frames` 和 `gain_db`。`lfe_fir` 使用经长度及 SHA-256 校验的一维小端 f64 数组。制作工具核对原房间的字节摘要、采样率、标签顺序、三种布局的测量配置和 FIR 一致性，然后生成新目录。版本 1 的既有房间继续直接加载。当前算法报告 256 帧块 FIFO，逐箱延时和完整低频 FIR 另计入适用会话的尾声、换房和跳转预滚。
