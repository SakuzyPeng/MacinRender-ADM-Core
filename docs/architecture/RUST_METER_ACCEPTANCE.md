> 对应 [PCM 一致性审计](PCM_CONSISTENCY_AUDIT.md)二期 2.4。前序切片：[2.1 True Peak](RUST_METER_TRUE_PEAK.md)、

## 范围

二期前三个切片让计量与反馈增益在三平台上逐位相同。2.4 按路线要求同时验收两件事：计量本身是否准确，
以及门控边界、跨采样峰值、长静音、分块、reset 与归一化后的最终 PCM 是否在三平台上逐位相同。验收分四部分：

| 部分 | 位置 | 判定 |
| --- | --- | --- |
| 独立准确性 | `rust/crates/mradm-dsp/tests/meter_acceptance.rs` | 与独立实现的 BS.1770-4 参考比较，并按 EBU Tech 3341 的容差检查合成信号 |
| 分块与 reset | 同上 | 同一平台内，不同分块与 reset 后的读数逐位相同 |
| 三平台逐位 | 内核探针 `meter-acceptance-{rate}.*` | 20 个文件设为门禁（模式 `meter-*`） |
| 归一化后的最终 PCM | `tests/unit/normalization_acceptance_test.cpp`（ctest `mr_adm_normalization_acceptance_tests`） | 重新测量写出的文件，目标达成且报告的指标描述该文件 |

验收中发现一处分块依赖并在本切片修复，见下文“分块”。

## 独立准确性

参考实现写在测试里，不经过 ebur128：使用 BS.1770-4 表 1、表 2 给出的 48 kHz K-weighting 系数（f64 直接 I 型），
按 100 ms 网格切 400 ms 块，依次应用 −70 LUFS 绝对门限与 −10 LU 相对门限，momentary 与 short-term 取最后 400 ms / 3 s。
测试信号仿照 EBU Tech 3341 的合成信号，期望值由信号推出，不读取被测计量的结果：

| 检查 | 采样率 | 结果 | 要求 |
| --- | --- | --- | --- |
| 1 kHz 立体声 −23 / −33 dBFS、−36/−23/−36、−72/−36/−23/−36/−72、−26/−20/−26 分段，5.0 声道 −28/−28/−24/−30/−30 dBFS：integrated、momentary、short-term 与参考比较 | 48 kHz | 差值不超过 3.2e-12 LU | < 1e-9 LU |
| 门限边界：交替电平 −69.9/−70.1、−69.98/−70.02（绝对门限）与 −20 搭配 −29.9/−30.1/−29.98/−30.02 dBFS（相对门限）；全程 −70.5 dBFS | 48 kHz | 与参考的取舍一致，integrated 差值不超过 3.2e-12 LU；全程低于门限时为 −inf | < 1e-9 LU |
| 上述节目的 integrated 与标称 −23 / −33 LUFS 比较 | 44.1、48、96、192 kHz | 最大偏差 0.041 LU（192 kHz） | ±0.1 LU |
| 周期等于窗长的猝发：1.34 s −20 / 1.66 s −30 dBFS 下的 short-term，0.18 s / 0.22 s 下的 momentary，窗满后每 10 ms 读一次 | 4 种采样率 | short-term 最大偏差 0.017 LU，momentary 0.042 LU | ±0.1 LU |
| 正弦的 True Peak（真值为幅度）：四分之一采样率、相位偏 45°（样本峰值低 3.01 dB），幅度 0.5、1/√2、1；以及 997、15013、19997 Hz | 44.1、48 kHz（4 倍过采样），96 kHz（2 倍） | 偏差 0 至 +0.104 dB，且不低于样本峰值 | +0.2 / −0.4 dB |
| 同上 | 192 kHz | 等于样本峰值 | 见下 |

48 kHz 下计量与参考的差约 3e-12 LU，来自 ebur128 按公式推出的系数与标准表格系数在末位的差别；门控的取舍与参考完全一致。

ebur128 在 192 kHz 及以上不做过采样，True Peak 就是样本峰值。对音频频段内的信号，这一做法最多低估
cos(π·20 kHz / 192 kHz)，约 0.47 dB；对接近 fs/4 的超声信号可低估到 3 dB。这是计量的既有行为（2.1 已记录过采样策略不变），
本切片只把它写成断言，不改变。

## 分块

渲染器按渲染块把输出送入计量，Monitor 按回调块送入，所以读数不应依赖分块大小。验收用 6 种分块
（整段、1、7、127、4800 帧，以及 1/4799/333/10007 帧循环）送入同一节目：噪声、正弦、数字静音、−60 dBFS 正弦、再静音。

**发现的问题。** 2.2 之后 ebur128 在每次 `Filter::process` 调用结束时把低于 `f64::EPSILON` 的滤波器状态清零。
同一段静音一次送入时，状态在调用内部继续衰减，输出仍是极小的非零值；逐帧送入时，状态一低于阈值就被清零。
因此静音段的 momentary 与 short-term 依赖分块：44.1 kHz 节目末的 momentary 在整段送入时是一个有限的极低值，
逐帧送入时是 −inf。integrated 与 True Peak 在这组节目中没有受影响，但从静音中恢复的信号在加和时理论上也可能差最后一位。

**修复。** vendored ebur128 的清零时机改为每完成一个 100 ms 块时（`Filter::clear_small_states`，由 `add_frames` 调用）。
块的完成位置只由 reset 以来的帧数决定，与调用如何切分无关，所以清零发生在相同的样本位置。`Filter::seed` 项目不使用，
保持原样。补丁记录在 `rust/vendor/ebur128/PATCHES.md`。

修复后 6 种分块在 4 种采样率下读数逐位相同。按 100 ms 对齐送入的节目不受影响：内核探针原有的计量文件中，
48 kHz（4800 帧分块正好是 100 ms）全部不变；44.1、96、192 kHz 只有节目末 2^-80 直流段的 momentary 改变：

| 文件 | 2.3 | 2.4 |
| --- | --- | --- |
| `meter-44100-2.30-loudness.f64` | −496.63 LUFS | −498.89 LUFS |
| `meter-44100-12.30-loudness.f64` | −491.99 | −494.25 |
| `meter-96000-2.30-loudness.f64` | −495.90 | −498.91 |
| `meter-96000-12.30-loudness.f64` | −491.27 | −494.28 |
| `meter-192000-2.30-loudness.f64` | −492.91 | −498.93 |
| `meter-192000-12.30-loudness.f64` | −488.27 | −494.29 |

这些读数远低于 −70 LUFS，不进入 integrated，也不进入响度归一化。

**reset。** 先送入无关的 440 Hz 信号再 reset，之后的读数与新建的计量逐位相同；节目中途 reset（相当于 Monitor 的 seek）
同样从空状态开始。

**模式差异（记录，不改变）。** Monitor 模式（short-term + integrated）为 short-term 保留 3 s 的环形缓冲，离线模式只保留 400 ms。
块能量按环形缓冲的回绕位置分两段加和，两种模式的加和顺序不同，同一节目的 integrated 可能在最后几位不同
（例如 −1.0958846652667005 与 −1.0958846652666967）。离线渲染使用离线模式，Monitor 使用 Monitor 模式，各自在三平台上一致。

## 长静音

节目后接 60 秒数字静音：1 秒后 momentary 回到 −inf，4 秒后 short-term 回到 −inf，integrated 与 True Peak 在 1、4、60 秒时逐位不变。
测试中延长到 10 分钟，结论相同。60 秒静音之后再送入节目，integrated 与 True Peak 与直接测量逐位相同：静音块全部低于绝对门限，
滤波器状态为精确的零。

## 三平台门禁

内核探针新增 `meter-acceptance` 模块，每个采样率（44.1、48、96、192 kHz，立体声）写 5 个文件。正弦由 `libm::sin`
按整数取模后的相位生成，噪声由整数 xorshift 生成，因此输入在三平台上相同。每组读数记录 Monitor 的 integrated、momentary、
short-term，以及离线模式的 integrated 与两声道 True Peak（−inf 记为 −1e300）。

| 文件 | 内容 |
| --- | --- |
| `10-gates.f64` | 7 组门限边界节目（同上，每个电平 1 秒，交替三次） |
| `20-true-peak.f64` | 10 种信号的两声道 True Peak：四分之一采样率正弦（4 种）、0.45 fs 与 997/15013/19997 Hz 正弦、1, 1, −1, −1 序列（真值 √2）、单个满幅样本 |
| `30-long-silence.f64` | 节目后静音 1、4、60 秒的读数，60 秒静音后再送入节目的读数 |
| `40-chunking.f64` | 6 种分块的读数 |
| `50-reset.f64` | reset 后的读数，节目中途 reset 前后的读数 |

全部 20 个文件由已有的 `meter-*` 门禁覆盖。内核文件由 193 个增至 213 个，门禁由 188 个增至 208 个。

## 归一化后的最终 PCM

`mr_adm_normalization_acceptance_tests` 渲染一个 ADM 夹具（1 kHz 正弦与一段采样点之间有峰值的四分之一采样率猝发，EAR 0+5+0），
在离线渲染写出后重新读取文件、用生产计量测量，并要求目标达成、`RenderResult` 报告的响度与峰值和文件一致：

| 用例 | 最终 PCM | 与目标的差 |
| --- | --- | --- |
| 响度目标 −23 LUFS | −23.00000016 LUFS | 1.6e-7 LU |
| 响度目标 −23 LUFS，最终增益 −2.5 dB | −25.5000004 LUFS | 4e-7 LU |
| 峰值补偿到 −6 dBTP（float） | −6.000000491 dBTP | 4.9e-7 dB |
| 峰值补偿到 −6 dBTP（24-bit 整数） | −6.000001524 dBTP | 1.5e-6 dB |
| 默认 −1 dBTP 上限，输入超过上限 | −1.000000871 dBTP | 8.7e-7 dB |
| 静音（响度与峰值都启用） | 数字静音，不报告响度与峰值 | — |

偏差来自 f32 增益、float 输出与 24-bit 量化，测试容差为 1e-5。锁定矩阵中的 `ear-loudness-minus23` 与 `ear-peak-minus6`
继续作为 PCM 门禁，要求归一化后的最终 PCM 在三平台上逐位相同。
