# 房间晚场生成器 `ray-energy-v1`（方案草案）

> 状态：草案，未实施，待维护者决定（见文末「待决定」）。日期：2026-11-24。
> 范围：`scripts/room/generate-room.py` 的晚场生成器（制作阶段）。不改 Rust 运行时、C ABI、
> CLI、资源清单格式和锁定矩阵。

## 动机

当前房间包的晚场由两种离线生成器产生：

- `octave-decay-noise-v1`：每个世界方向、每个频带用固定种子噪声乘指数衰减
  `exp(-ln(1000)·t/RT60)`，各方向统计上完全相同；
- `template-orthogonal-mix-v1`：对模板晚场做一个能量守恒的正交变换，再加一个共同的指数倾斜。

两者都不来自房间几何：方向能量分布、各频带衰减形状和起始段的建立过程都是参数或模板继承。
运行时的晚场发送（`mradm-dsp` `room::prepared` 的 `late_send_many`）只按声源距离给延时，
32 个方向的增益相同（`sqrt(late_energy / 方向数)`），方向结构完全由 `late` 资源决定。

`ray-energy-v1` 用房间几何和材料做随机射线追踪，得到「世界方向 × 频带 × 时间」的能量分布，
再合成同样形状的 `late` 资源。运行时不变，所以它只改变房间包的内容。

## 运行时契约（生成器必须满足）

以下由运行时代码决定，生成器只能产出满足它们的资源：

| 项 | 要求 | 依据 |
|---|---|---|
| 资源形状 | `late`：`<f4`，`[方向数, late_taps]`；方向基 `late_directions` 从模板逐字节复制 | `resources.rs` 的 `RoomProfile::parse` |
| 方向基 | 数量、顺序、f64 数值与模板相同，否则不能与模板系列房间互相切换 | `session.rs` 的 `validate_room` |
| 时间零点 | `late[d][0]` 对应「直达到达 + `late_predelay_seconds`」（加上运行时自己的保护延迟） | `late_send_many` |
| 坐标 | 方向是房间坐标的单位向量：+X 前、+Y 左、+Z 上，听者为原点 | `geometry.rs` |
| 与声源无关 | 每个声源共用同一组方向 FIR，只差延时 | `late_send_many` |
| 电平 | 只做一次共同校准：方向平均能量为 1，整体电平由 `late_energy` 决定；不做逐方向 / 逐耳归一化 | `noise_field` 的约定 |
| 尾声 | `duration_seconds` 为 0.1–10 s；末尾 5 ms 线性淡出；没有反馈网络，支持有限 | 同上；尾长进入 history / preroll / EOS |
| 频带 | 使用模板 `bands`（8 × 512 的八频带综合滤波器），不另造滤波器组 | `noise_field` |
| 采样率 | 与模板相同（48 或 96 kHz） | `manifest` |

因此 `ray-energy-v1` 不改 `kind`（仍为 `hybrid-shoebox-v1`），早反射（四阶镜像源）也不变。

## 算法

### 1. 几何与材料

- 长方体，尺寸与听者取自定义文件的 `dimensions` / `listener`，墙序与 `absorption` 相同：
  west、east、south、north、floor、ceiling。
- **射线追踪使用单独的物理材料**：`late.materials.absorption[6][8]` 与 `late.materials.scattering[6][8]`。
  不复用顶层 `absorption`：后者是镜像源早反射的模型参数（参考包为 0.94，见
  [实时房间](REALTIME_ROOM_RENDERING.md)），用它追踪射线会得到几乎没有混响的房间。
  早晚两套参数描述的不是同一物理房间，这是本版本的已知限制，报告里写明，不在生成器中自动统一。
- 可选空气吸收 `late.air_attenuation_db_per_m[8]`，缺省为 0。

### 2. 声源与发射

- 声源集合缺省为 `scripts/room/reference-positions.json` 的 28 个位置（22.2 的 22 个全频位置与
  6 个补点），也可以在定义中给出显式列表；记录所用列表的 SHA-256。
- 指向性与运行时一致：声源朝向听者，幅度按 `beam²`（`geometry.rs` 的 `path`，背半球为 0），
  所以射线的初始能量权重为 `beam⁴`。实现时以 `geometry.rs` 的定义逐项核对。
- 每个声源发射 `rays` 条射线，方向按球面分层抖动采样（固定种子），能量按权重分配，
  声源总功率相同。

### 3. 传播与反射

- 每次碰墙：能量乘以 `(1 - α_b)`（逐频带）；以概率 `s_b` 做 Lambert 漫反射，否则镜面反射。
  为让 8 个频带共用一条路径，采用「能量向量」形式：每条射线只有一条几何路径，漫反射与镜面反射
  的选择按**宽带平均散射系数**抽样，频带间的差异用权重修正（`s_b / s̄` 与 `(1 - s_b)/(1 - s̄)`），
  保证每个频带的期望不变。
- 终止：任一射线的所有频带能量都低于初始能量的 −120 dB，或传播时间超过 `duration_seconds +
  late_predelay_seconds + 直达时间`。不做俄罗斯轮盘赌，避免引入额外方差。

### 4. 接收与直达对齐

- 听者处放一个半径 `receiver_radius` 的球形接收器；射线穿过球时贡献
  `能量 × 球内弦长 / 球体积`（Kuttruff 的体积接收器），到达方向取射线方向的反向。
- **去掉直达声**：没有发生过反射的射线不计入。
- 每个声源 s 的时间轴换算为相对时间 `τ = t − t_direct(s) − late_predelay_seconds`，
  与运行时 `late[d][0]` 的零点一致；`τ < 0` 的能量不进入晚场。
- 28 个声源的直方图在相对时间轴上直接平均，得到与声源无关的晚场（运行时契约）。

### 5. 与早反射的衔接

运行时的镜像源早反射在相对直达时间 15–25 ms 之间以升余弦淡出（`early_fade_seconds`，
`geometry.rs`）。为避免同一段能量算两次，生成器把晚场能量乘以互补窗：
`w(τ) = 1 − fade(τ + late_predelay_seconds)`。
预延时晚于淡出起点时（参考包为 18 ms 对 15 ms），15–18 ms 之间的互补部分无法表示；
生成器计算并记录这部分丢失的能量占比（`uncovered_onset_energy_ratio`）。

### 6. 方向分配

到达方向分配到 32 个 `late_directions`，用归一化的 von Mises–Fisher 核
（`direction_kappa`，缺省对应约 20° 的展宽）做软分配：每次到达的权重和为 1，总能量不变，
避免最近邻分配在方向边界产生阶跃。生成器检查分配前后总能量的相对误差 ≤ 1e-12。

### 7. 直方图与尾段

- 直方图按 `histogram_seconds`（缺省 1 ms）分箱，按 8 个频带、32 个方向各自累计。
- 尾段射线命中稀疏、噪声大：对每个「方向 × 频带」，从累计命中数低于 `min_hits_per_bin`（缺省 32）
  的第一个分箱开始，改用前一段能量衰减曲线（Schroeder 积分在 −5 到 −25 dB 区间）拟合的指数
  衰减外推。记录每个方向 × 频带的外推起点和拟合斜率；拟合失败（斜率非负或点数不足）时报错，
  不静默改用默认值。

### 8. 合成 FIR

与 `noise_field` 相同的结构，只把包络换成射线结果：

1. 每个方向、每个频带生成独立的固定种子高斯噪声，经模板 `bands[b]` 滤波；
2. 把该频带的能量直方图换成幅度包络 `sqrt(E_d,b(τ) / Δt)`，在分箱中心之间线性插值到逐样本，
   乘以滤波后的噪声（噪声方差已按频带归一化）；
3. 8 个频带求和，末尾 5 ms 线性淡出；
4. 全部方向一起按「方向平均能量为 1」校准一次，写为 `<f4`。

随机数用 `numpy.random.PCG64`，射线种子与噪声种子分别由 `late.seed` 派生，互不影响。

## 定义文件

在现有 `mradm.room-definition` v1 中只扩展 `late` 对象，其余字段不变：

```json
"late": {
  "generator": "ray-energy-v1",
  "seed": 1,
  "duration_seconds": 1.0,
  "rays": 200000,
  "receiver_radius": 0.3,
  "histogram_seconds": 0.001,
  "min_hits_per_bin": 32,
  "direction_kappa": 8.0,
  "source_positions": "reference-positions",
  "materials": {
    "absorption": [[0.10, 0.10, 0.12, 0.15, 0.18, 0.20, 0.22, 0.25], "…共 6 行"],
    "scattering": [[0.10, 0.10, 0.15, 0.20, 0.30, 0.40, 0.50, 0.60], "…共 6 行"]
  },
  "air_attenuation_db_per_m": [0, 0, 0, 0, 0, 0, 0, 0]
}
```

示例数值只说明格式，不是推荐材料。所有数值检查有限值和范围（α、s ∈ [0, 1]，`rays` ≤ 10⁷，
`receiver_radius` 在 0.05–1 m 且小于听者到墙的距离）。

`generation` 元数据追加：射线数与种子、实际使用的声源列表 SHA-256、每个频带的
T30 / EDT（来自平均直方图）、方向能量分布、外推起点与斜率、`uncovered_onset_energy_ratio`、
方向分配误差、运行耗时和 numpy / scipy 版本。`validation_scope` 沿用「新预设，需要独立声学验收」。

## 实现位置

- 新文件 `scripts/room/ray_energy.py`（追踪、接收、直方图、外推、合成，纯 numpy / scipy），
  `generate-room.py` 新增一个 `late["generator"] == "ray-energy-v1"` 分支调用它；
  生成器的其余部分（资源复制、哈希、清单）不变。
- 依赖只有已用的 numpy / scipy，不引入 pyroomacoustics（它只用于下面可选的交叉核对）。
- 计算量估计：28 个声源 × 2×10⁵ 条射线 × 约 200 次反射（RT60 ≈ 0.5 s 的中等房间）
  约 10⁹ 次碰撞，按射线向量化、按反射次数循环，预计在分钟级。若过慢，先降低每源射线数并
  依赖 28 个源的平均，不做精度换速度的近似。
- 与现有生成器一样：只在维护者机器上生成一次，各平台分发同一份资源字节；不要求不同
  numpy 版本逐位相同。

## 验收

### 生成器自测（新增 `scripts/room/test_ray_energy.py`，不需要构建）

1. **无吸收守恒**：α = 0 时，平均直方图在 `duration_seconds` 内不衰减（统计容差内）。
2. **扩散场衰减**：六面相同 α、s = 1 时，各频带 T30 与 Eyring 公式的相对差 ≤ 10%。
3. **方向各向同性**：s = 1 时 32 个方向的能量相对标准差在射线数决定的统计界内；
   只有一面墙吸收较强时，来自该墙方向的能量明显偏低（方向与坐标约定的正向检查）。
4. **能量账**：方向软分配误差 ≤ 1e-12；互补窗前后的能量差与 `uncovered_onset_energy_ratio` 一致。
5. **确定性**：同一机器、同一种子两次生成的 `late.f32` 逐字节相同；不同种子的 T30 差异在统计界内。
6. **错误路径**：非法材料、射线数越界、外推拟合失败都报错，不生成输出目录。

每项都先植入缺陷（如去掉漫反射权重修正、方向符号取反）确认会失败。

### 资源与运行时

1. `mradm room-check` 通过（形状、哈希、有限值、FFT 准备），报告的尾长与 `duration_seconds` 一致。
2. 与模板包互相切换：方向基相同，`*_switch_room` 正常交叉淡化。
3. 现有锁定矩阵、内核门禁和 `room_replay` 冻结回放不受影响（不改运行时，也不改已有房间包）。
   新预设第一版不进门禁矩阵；以后要进，按 `collection_tools_test.py` 的规则同步加入门禁。

### 声学

1. `check-acoustics.py` 用 `room_omni` 测量 28 个位置：各频带 RT、EDT、频响，与
   生成器自己报告的 T30 对照（运行时与生成器一致性）。
2. 可选交叉核对：用 pyroomacoustics 的镜像源加射线追踪混合模型，在同一几何与材料下比较
   各频带 T30（相对差 ≤ 15%）。PRA 只作独立参考，不作为生成器依赖。
3. 与相同 RT60 的 `octave-decay-noise-v1` 预设做双耳 A/B 试听，记录方向感、包围感和起始段的差别。
   试听不是门禁，结论写进验收报告。

## 不做的事

- 不改运行时：晚场仍与声源位置无关（只差延时），不做按声源位置查表的晚场发送。
  那需要改 `late_send_many` 与资源格式，另开 ADR。
- 不做衍射、非长方体几何和移动听者。
- 不统一早反射与晚场的材料模型，也不从射线追踪推导物理电平；`late_energy` 仍是电平参数。
- 不做运行时射线追踪（另见对话中讨论的固定流水线方案，届时另开 ADR）。
