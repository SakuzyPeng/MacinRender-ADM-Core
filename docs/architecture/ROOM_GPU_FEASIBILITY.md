## 实测范围

测试机为 i7-11800H（8 核／16 线程）、RTX 3060 Laptop GPU（6 GiB），驱动 610.88，使用已安装的
CUDA 12.0／cuFFT 和 canonical MSVC 环境。没有安装新依赖或创建另一份大项目构建缓存。

输入是现有原生 96 kHz 房间和完整九层 HRIR 集合：1850 个方向、4096 点响应 FFT、7071 抽头
完整 FIR、129 个镜像项。16 个位置／距离快照每个包含 32 源，最多 654 条原模型增益非零的路径。
GPU 每 256 帧重建所有源的直达／早反射响应，一次 512 帧调用执行两次，随后构造 28 个完整
卷积分区。最终压力配置同时计算 16 个活动目标；滤波器、输入历史和 FFT 计划常驻 GPU。

计时包含主机描述符复制、输入生成、上传、Graph 提交、GPU 处理、回传、同步和输出复制，
没有 GPU 事件／内层剖析。初始化、文件读取、JIT、分配和 FFT 计划构建在计时外；预热 32 次。
每项短测 1024 次，在两次调用间等待到 512／96000 秒的周期；等待和唤醒晚点不计入处理耗时。
只有一个主机提交线程，尚未计入完整 Session 的八个音频 worker。

**几何和查询描述符已经预计算，快照循环不是完整基准的连续轨迹与分散事件网格。**
EQ、晚场、LFE、headLocked／extent、换房、FIFO／seek／reset 及设备均未接入。
活动目标采用等权混合测占用成本，没有实现产品的 10 ms 有限淡化。不能把组件耗时直接除以
原 CPU 完整会话耗时来宣称整链加速，也不能把零次组件超时报告为设备零欠载。

| 快照序列 | 调用数 | 均值 | p99 | 最大值 | 超过 5.333333… ms |
|---|---:|---:|---:|---:|---:|
| 位置运动 | 1024 | 3.718 | 4.336 | 4.660 | 0 |
| 距离运动 | 1024 | 3.389 | 4.010 | 4.235 | 0 |

在此前同一算术内核的复核中，两项同样各 1024 次零超时，最慢观察值为 **4.905 ms**。
保留该较慢结果，意味着到原期限只余 **0.428 ms**，未证明足以容纳尚未计时的 CPU 工作。
最终主机程序只修正了参考文件字节到浮点数组的读取方式，并重新执行了上述两项短测；CUDA
内核和被计时的处理流程未改。所有初筛、复核与源码／二进制身份保存在
[validation.json](evidence/room-gpu/validation.json)。没有运行六轮长测或 macOS 性能矩阵。

## 正确性边界

CPU 参考由本地 macOS arm64 的 Release `ResponseWork` 导出，GPU 使用同一份准备表和描述符。
对 16 × 32 × 4＝2048 个源／分支／耳平面，比较每个完整 7071 抽头响应：

- 最坏相对 L2：`4.245e-7`。
- 最坏最大误差／参考峰值：`2.687e-7`。
- 另以完整输入历史检查最初 512 帧卷积输出，16 目标下相对 L2 `2.101e-6`，峰值比例 `4.007e-6`。

均低于 `2e-5`／`2e-4`，不作对齐、增益拟合或裁剪，静音与有限值检查通过。
GPU 保持 f32，几何和时延分解保留 CPU f64；启用 FMA，未开启 fast-math／FTZ 或低精度模式。
这些检查不替代同机旧 realtime 与完整候选的 PCM、元数据时序、延迟和完整尾声验收。

Rust 导出器 clippy（warnings denied）、C++ cppcheck、格式检查、Python 工具语法和 Windows CLI
烟测通过。Windows 原 HEAD／Git 状态未变，临时研究目录及私人频谱已清理；本地临时大载荷亦删除。
原有未提交研究与规则修改保持原样。

## 下一步的具体边界

优先评估 GPU 常驻整段算术，仅回传 PCM。完整集成需要把当前逐声源执行改成有明确边界的批量任务：
收集实际事件对应的目标、执行 GPU 处理、按原样本位置混合；保留全部分支、有限淡化和尾声。
CPU 准备和晚场能否与 GPU 重叠、多少工作必须串行，必须由完整原型测量，不能从阶段累计时间相加推算。

还需处理真实事件导致的多次目标更新、GPU 与桌面图形竞争、设备错误和资源回收；随后按既定
8 workers／96 kHz／512 帧／32 源，先做 Windows 两项完整会话 1024 次短测，任一超时即停止候选。
CUDA 证据只适用于该 NVIDIA／Windows 路线，未实现或验证 macOS GPU 后端。

源码、计时边界和完整命令见 [探针说明](../../scripts/research/room_gpu/README.md)。
